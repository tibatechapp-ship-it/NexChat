Rasan — chat without a number

## Short description (≤ 80 chars)

End-to-end encrypted group chat. No phone number. Tiny, fast on weak networks.

## Full description

Rasan is an **end-to-end encrypted** group messenger that never asks for your
phone number — a username is enough. The Arabic interface is native (RTL) and
the web client weighs about 7 KB gzipped, so it opens fast even on weak
networks.

**Why Rasan?**
- 🔒 E2EE by default (ECDH P-256 + AES-GCM) — not even the server operator can read your messages
- 🚫 No phone number: no identity exposure, no address-book linking
- 🪶 Tiny: ~7 KB web UI + a mobile app for secure notifications
- 👥 Large communities: groups up to 50,000 members, stories, polls, group calls
- 🛡️ Full community moderation + emergency modes (panic wipe, walkie-talkie)
- 🌐 Self-hostable — your data stays on your server

**Honest note**: group-wide MLS encryption (RFC 9420) is under development —
direct chats are fully encrypted today.
